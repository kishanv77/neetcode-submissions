## Question: Print Numbers Using Recursion

Write a program to print numbers from **1 to N**, **N to 1**, and in the pattern **1 to N followed by N to 1** using recursion.

### Input
A single integer `N`.

### Output
Print the following three sequences:

1. Numbers from **1 to N**
2. Numbers from **N to 1**
3. Numbers from **1 to N and then N to 1**

### Example

**Input:**
```text
5
```

**Output:**
```text
1 2 3 4 5
5 4 3 2 1
1 2 3 4 5 5 4 3 2 1
```

### Constraint
- `1 ≤ N ≤ 1000`

**Note:** The solution must use **recursion** and should not use loops for printing the sequences.
